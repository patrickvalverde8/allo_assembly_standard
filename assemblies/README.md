# 装配文件说明

本目录包含各种设计示例，展示不同的设计风格和技术。

## 装配列表

### 01_simple_lamp.json
**简单台灯**

基础的四柱框架结构，适合初学者。

**特点**：
- 4个底座支撑（SK8）
- 4根竖直光轴
- 简单的顶部连接
- 尺寸：200×200×300mm

### 02_box_lamp.json
**机箱风格灯具**

完整的立方体框架结构。

**特点**：
- 8个角节点（底部SK8 + 顶部cross）
- 12条光轴（4竖直 + 8横向）
- 顶板和底板
- 尺寸：200×200×300mm

### 03_complex_lamp.json
**复杂错位灯具**

展示光轴错位美学的复杂结构。

**特点**：
- 21个节点
- 光轴错位布局
- 4块玻璃面板（90×90mm）
- SC6夹持玻璃
- 尺寸：150×150×280mm

### 04_compact_lamp.json
**紧凑型台灯**

小巧精致的台灯设计。

**特点**：
- 双竖直支撑
- 横向连接
- 玻璃面板装饰
- 尺寸：约100×60×150mm

### 05_creative_lamp.json
**创意不对称台灯**

展示不对称设计和旋转节点的使用。

**特点**：
- 左右不对称结构
- T型节点旋转使用
- 玻璃夹持组合
- 尺寸：60×60×130mm

### 06_deconstructed_car.json
**解构主义小汽车**

展示解构主义设计理念。

**特点**：
- 车身框架结构
- 4个车轮面板
- 车顶支撑
- 独立结束的光轴
- 尺寸：100×60×60mm

## 创建新装配

1. 在此目录创建 JSON 文件
2. 参考 `docs/02_构建JSON规则.md` 了解设计流程
3. 定义节点、光轴、面板
4. 运行 `python build.py assemblies/your_file.json`

## JSON 基本结构

```json
{
  "name": "装配名称",
  "unit_mm": 1.0,
  "nodes": [...],
  "rods": [...],
  "panels": [...],
  "rod_attachments": [...]
}
```

详细格式说明请参考文档目录。

## 可用节点类型

| 节点类型 | 说明 | 端口数 |
|---------|------|--------|
| `node_SK8_support` | 底座支撑 | 1 |
| `node_T_6x6` | T型连接件 | 2 |
| `node_cross_6x6` | 十字连接件 | 2 |
| `node_parallel_6x6_c10` | 平行连接件 | 2 |
| `node_SC6_ring` | 固定环 | 1 |

详见 `nodes/components.json` 和 `docs/03_节点端口说明.md`

## 设计建议

- 整体尺寸建议 300mm 左右
- 节点间距建议 >= 30mm
- 光轴可以独立结束（悬臂结构）
- 面板 position 定义在底面中心
- SC6 环间距 11mm（用于夹持 3mm 玻璃）

更多设计指南请参考 `docs/` 目录。
