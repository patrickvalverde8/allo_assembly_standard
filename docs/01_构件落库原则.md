# 构件落库原则

## 坐标系规范

### 全局坐标系
- 右手坐标系
- +X：向右
- +Y：向前
- +Z：向上
- 单位：毫米 (mm)

### 节点局部坐标系

每个节点的原点位置必须明确定义。

#### 当前原点定义

| 节点 | 原点位置 |
|------|---------|
| 十字连接件 6×6 | 右侧孔（+Y方向）的中心点 |
| T型连接件 6×6 | 右侧孔（+Y方向）的中心点 |
| 平行连接件 6×6 中心距10 | 右侧孔（+Y方向）的中心点 |
| 固定环 SC6 | 光轴中心线，环厚度中心平面 |
| SK6支撑座 | 光轴中心线与底座上表面交点 |
| SK8支撑座 | 光轴中心线与底座上表面交点 |

## STEP 文件要求

### 文件命名
- 格式：`node_<ID>.stp` 或 `node_<ID>.step`
- 示例：`node_cross_6x6.stp`

### 坐标系要求
1. 原点位置必须符合上表定义
2. 轴向与全局坐标系平行
3. 单位：毫米 (mm)

### 存储位置
```
nodes/
├── node_cross_6x6.stp
├── node_T_6x6.stp
├── node_parallel_6x6_c10.stp
├── node_SC6_ring.stp
├── node_SK6_support.stp
└── node_SK8_support.stp
```

## JSON 定义

在 `nodes/components.json` 中定义节点：

```json
{
  "id": "node_cross_6x6",
  "category": "node",
  "name": "十字连接件 6×6",
  "local_frame": {
    "origin_rule": "右侧孔（+Y方向）的中心点"
  },
  "ports": [
    {
      "id": "y_pos",
      "type": "rod_axis",
      "position": [0, 0, 0],
      "axis": [0, 1, 0],
      "compatible_rod": "rod_3mm",
      "through": true,
      "insert_from": ["positive"],
      "max_rods": 1,
      "occupied_length_mm": 6.0
    }
  ]
}
```

### 端口定义字段

- `id`: 端口唯一标识
- `type`: `"rod_axis"` 或 `"panel_mount"`
- `position`: 相对于原点的位置 [x, y, z]
- `axis`: 轴向（单位向量）
- `compatible_rod`: 兼容的光轴类型
- `through`: 是否贯穿
- `insert_from`: 允许插入方向 `["positive", "negative"]`
- `max_rods`: 最大连接光轴数
- `occupied_length_mm`: 节点沿轴向占用长度

## 验证流程

1. 在 CAD 软件中导出 STEP 文件
2. 确保坐标系正确
3. 放入 `nodes/` 目录
4. 在 `nodes/components.json` 中定义
5. 运行测试：`python build.py assemblies/01_nodes_test.json`
6. 检查输出文件
