## 🧠 设计思维流程（重要！）

### 在生成 JSON 之前，请先输出思考过程

使用以下结构组织你的思考：

```
<thinking>
1. 设计意图：[用一句话描述整体设计目标]
   - 如果是解构主义设计，先描述要解构的对象（如：小汽车、月球、建筑等）

2. 形状规划：[先规划整体形状和主要体块]
   - 例如：车身主体是一个长方体 [200×120×80]
   - 车轮是四个圆柱体，位置在四角，直径 40mm
   - 车顶是一个小方块 [120×80×40]
   - **建议整体尺寸 300mm 左右**

3. 支撑结构设计：[根据形状，规划光轴骨架]
   - 例如：底部四角需要竖直支撑（高度 80-150mm）
   - 车身周围需要横向框架（跨度 100-200mm）
   - 哪些地方需要面板，哪些地方留空
   - **节点间距建议 ≥ 30mm**

4. 节点位置规划：[确定节点的具体坐标]
   - 例如：底层四角节点在 z=0
   - 中层节点在 z=80-120
   - 顶层节点在 z=150-250
   - 考虑节点的端口方向
   - **层间距建议 50-100mm**

5. 光轴连接关系：[说明哪些节点通过光轴连接]
   - 例如：base_1 → mid_1 (竖直)
   - mid_1 → mid_2 (横向)
   - **注意**：光轴可以独立结束，不需要所有端头都套节点

6. 面板和装饰：[添加面板、玻璃等元素]
   - 例如：车身侧面用面板封闭
   - 车窗用玻璃 + SC6 夹持
   - **注意**：面板 position 定义在底面中心，不是几何中心

```

然后再输出最终的 JSON。

### 解构主义设计方法

这套系统可以用来设计**任何解构化的物体**：

**设计步骤**：
1. **选择对象**：月球、小汽车、建筑、家具等
2. **抽象形状**：将对象分解为简单几何体（方块、圆柱、平面）
3. **设计骨架**：用光轴和节点构建支撑结构
4. **添加表面**：用面板表现主要特征
5. **留白艺术**：不需要完全封闭，保持通透感

**示例思路**：
- **月挂东南枝**：球体（方块近似）+ 几根斜向光轴 + 底座
- **解构小汽车**：车身框架 + 四个轮子位置 + 车窗玻璃
- **建筑模型**：楼层框架 + 墙面板 + 窗户

### 常用组合模式参考

以下是经过验证的设计模式，**可以参考但不强制使用**：

- **玻璃夹持组合**：SC6上环 → 玻璃 → SC6下环（详见 `docs/04_常用组合模式.md`）
- **竖直支撑链**：底座 → 中层节点 → 顶层节点
- **横向桥接**：左侧节点 ←→ 右侧节点
- **T型分支**：使用 T_6x6 实现三向连接
- **十字分支**：使用 cross_6x6 实现四向连接

详细说明请参考：`docs/04_常用组合模式.md`

## 基本原则

### 1. 光轴不能重叠
**错误示例**：
```
    N1 (十字)
   /|\
  / | \  ← 三根光轴从同一点出发（不可行）
```

**正确示例**：
```
N1 --- N2 --- N3
       |
       N4
```
使用多个连接件实现三向连接。

### 2. 节点端口限制
- 十字连接件：2 根光轴（Y方向 + Z方向，都可穿过）
- T型连接件：2 根光轴（Y方向穿过 + X负方向插入）
- 平行连接件：2 根光轴（两个平行的Y方向孔）
- 每个端口只能连接 1 根光轴

### 2.5. 光轴端头处理
**重要**：光轴不需要所有端头都连接节点！

- **底座端**：建议使用 SK8/SK6 支撑座固定
- **其他端**：可以自由结束，形成悬臂结构
- **美学考虑**：独立的光轴端头更有工业感

**示例**：
```json
{
  "rods": [
    {
      "id": "cantilever_rod",
      "component_id": "rod_3mm",
      "from": {"node": "base", "port": "rod_axis", "side": "positive"},
      "to": {"node": "mid", "port": "main_y_neg", "side": "negative"}
    }
  ]
}
```
这根光轴从 base 出发，到 mid 结束，mid 的另一端可以是自由端。

### 3. SC6 固定环的作用
**用途**：夹住玻璃面板

**重要**：
- SC6 环厚度：8mm
- SC6 原点：环中心
- 面板位置：环的 **±4mm** 处（贴合环表面）
- 玻璃厚度：3mm
- 两个 SC6 间距：11mm

**示例**：
```
光轴（蓝色）
 |
[SC6]  ← 上固定环（红色，环中心 Z=100）
 |     面板在 Z=96（环的 -4mm）
[玻璃] ← 3mm 厚（绿色）
 |     面板底 Z=93
[SC6]  ← 下固定环（红色，环中心 Z=89）
 |
```

**计算公式**：
- 上环中心：Z = h
- 下环中心：Z = h - 11
- 面板位置：Z = h - 4 - 1.5（面板中心）
- 或：Z = (h + (h-11)) / 2 = h - 5.5

### 4. 尺寸建议
- **整体尺寸**：建议 300mm 左右，最大 500mm × 500mm × 500mm
- **节点间距**：建议 ≥ 30mm，常用 50-100mm
- **面板尺寸**：建议 50-200mm
- **光轴长度**：建议 30-300mm

**尺寸参考**：
- 小型装饰灯：100-150mm
- 中型台灯：200-300mm
- 大型装置：300-500mm

### 5. 面板要求
- 材质：玻璃
- 厚度：3mm
- 圆角：需要圆角（小圆角）
- 固定：至少 4 点定位（用 SC6 夹住）
- **重要**：面板的 `position` 定义在**底面中心**，不是几何中心
  - 例如：厚度 3mm 的面板，position 在底面，顶面在 position + 3mm

### 6. 美学原则
- 光轴错位布局（不对称）
- 多使用节点（丰富视觉）
- 避免简单的立方体框架

## 常见错误

### ❌ 错误 1：光轴重叠
```json
{
  "nodes": [
    {"id": "N1", "component_id": "node_cross_6x6", "position": [0, 0, 0]}
  ],
  "rods": [
    {"from": {"node": "N1", "port": "x_pos"}, ...},
    {"from": {"node": "N1", "port": "y_pos"}, ...},
    {"from": {"node": "N1", "port": "z_pos"}, ...}
  ]
}
```
问题：三根光轴从同一点出发，实际上会重叠。

### ✅ 正确：使用多个节点
```json
{
  "nodes": [
    {"id": "N1", "component_id": "node_cross_6x6", "position": [0, 0, 0]},
    {"id": "N2", "component_id": "node_cross_6x6", "position": [100, 0, 0]},
    {"id": "N3", "component_id": "node_cross_6x6", "position": [0, 100, 0]}
  ],
  "rods": [
    {"from": {"node": "N1", "port": "x_pos"}, "to": {"node": "N2", "port": "x_neg"}},
    {"from": {"node": "N1", "port": "y_pos"}, "to": {"node": "N3", "port": "y_neg"}}
  ]
}
```

### ❌ 错误 2：SC6 位置不对
```json
{
  "rod_attachments": [
    {"node": "ring1", "rod": "rod1", "offset_mm": 50.0},
    {"node": "ring2", "rod": "rod1", "offset_mm": 60.0}
  ]
}
```
问题：两个 SC6 间距只有 10mm，无法夹住 3mm 玻璃。

### ✅ 正确：SC6 间距 11mm
```json
{
  "rod_attachments": [
    {"node": "ring1", "rod": "rod1", "offset_mm": 50.0},
    {"node": "ring2", "rod": "rod1", "offset_mm": 61.0}
  ]
}
```

## 设计流程

### 1. 规划结构
- 草图绘制整体布局
- 确定节点位置
- 规划光轴路径（错位）

### 2. 放置节点
- 从底部开始
- 逐层向上
- 确保光轴不重叠

### 3. 连接光轴
- 每个端口只连一根
- 检查方向（side）

### 4. 添加面板
- 确定面板位置
- 计算 SC6 位置（间距 11mm）
- 至少 4 点固定

### 5. 验证
```bash
python build.py assemblies/your_file.json
```

## 端口参考

### 十字连接件
- `x_pos`, `x_neg` - 左右
- `y_pos`, `y_neg` - 前后
- `z_pos`, `z_neg` - 上下

### T型连接件
- `y_pos`, `y_neg` - 前后
- `x_neg` - 左

### 平行连接件
- `right_axis` - 右孔（原点）
- `left_axis` - 左孔（-10mm）

### 支撑座/固定环
- `rod_axis` - 光轴孔

## 坐标系

```
     +Z (上)
      |
      |
      +------ +X (右)
     /
    /
  +Y (前)
```
