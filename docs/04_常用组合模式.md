# 常用组合模式（Combo Patterns）

这些是经过验证的常见设计模式，**可以作为参考，但不是强制要求**。你可以自由组合和变化，根据实际需求调整。

---

## 1. 玻璃夹持组合（Glass Clamping）

### 结构
```
    光轴
     |
  [SC6上环]  ← 固定环（环中心）
     |
  [玻璃板]   ← 玻璃面板（3mm厚）
     |
  [SC6下环]  ← 固定环（环中心）
     |
    光轴
```

### 几何约束
- **SC6 环厚度**：8mm
- **SC6 原点**：环中心
- **玻璃厚度**：通常 3mm
- **两环间距**：11mm（环中心到环中心）
- **面板位置**：在环的 ±4mm 处（贴合环表面）

### 计算公式
**重要**：面板的 `position` 定义在**底面中心**，不是几何中心！

假设玻璃底面在 z = h，厚度 3mm：
- **玻璃顶面**：z = h + 3
- **上环中心**：z = h + 3 + 4 = h + 7（贴合玻璃顶面）
- **下环中心**：z = h - 4（贴合玻璃底面）
- **两环间距**：(h + 7) - (h - 4) = 11mm ✓

**简化公式**（玻璃底面在 z = h）：
- 上环 = h + 7
- 下环 = h - 4
- 间距 = 11mm

    },
    {

    }
  ],
  "rods": [
    {
      "id": "vertical_rod",
      "component_id": "rod_3mm",
      "from": {"node": "base", "port": "rod_axis", "side": "positive"},
      "to": {"node": "top", "port": "rod_axis", "side": "negative"}
    }
  ],
  "rod_attachments": [
    {
      "node": "ring_top",

### 使用场景

- 创建透明隔板
- 装饰性玻璃元素

## 2. 竖直支撑链（Vertical Support Chain）

### 结构
```
  [顶层节点]  ← T_6x6 或 cross_6x6
      |
    光轴
      |
  [中层节点]  ← T_6x6 或 cross_6x6
      |
    光轴
      |
  [底座节点]  ← SK8 或 SK6
```

### 常见配置
- **底座**：SK8 或 SK6（单端口向上）
- **中层**：T_6x6 或 cross_6x6（多端口，可横向连接）
- **顶层**：T_6x6、cross_6x6 或 SK8

### 端口选择
- 底座 → 中层：`rod_axis` (positive) → `main_y_neg` 或 `sub_z_neg`
- 中层 → 顶层：`main_y_pos` 或 `sub_z_pos` → 对应端口

### JSON 示例
```json
{
  "nodes": [
    {
      "id": "base_1",
      "component_id": "node_SK8_support",
      "position": [0, 0, 0],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "mid_1",
      "component_id": "node_T_6x6",
      "position": [0, 0, 80],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "top_1",
      "component_id": "node_T_6x6",
      "position": [0, 0, 140],
      "rotation_deg": [0, 0, 0]
    }
  ],
  "rods": [
    {
      "id": "rod_v1",
      "component_id": "rod_3mm",
      "from": {"node": "base_1", "port": "rod_axis", "side": "positive"},
      "to": {"node": "mid_1", "port": "main_y_neg", "side": "negative"}
    },
    {
      "id": "rod_v2",
      "component_id": "rod_3mm",
      "from": {"node": "mid_1", "port": "main_y_pos", "side": "positive"},
      "to": {"node": "top_1", "port": "main_y_neg", "side": "negative"}
    }
  ]
}
```

### 注意事项
- 确保光轴方向一致（都是竖直的）
- 中层节点可以用于横向连接
- 计算好各层高度

## 3. 横向桥接（Horizontal Bridge）

### 结构
```
[左节点] ←─── 光轴 ───→ [右节点]
```

### 端口选择规则
- **沿 Y 轴连接**：使用 `main_y_pos` 和 `main_y_neg`
- **沿 X 轴连接**：使用 `sub_x_neg`（T型）或其他 X 方向端口
- **沿 Z 轴连接**：使用 `sub_z_pos` 和 `sub_z_neg`

### 关键约束
- 两个节点的对应坐标必须相同（如沿Y轴连接，则 X 和 Z 相同）
- 端口轴向必须对齐
- 一个端口 positive，另一个 negative

### JSON 示例（Y轴桥接）
```json
{
  "nodes": [
    {
      "id": "left_node",
      "component_id": "node_T_6x6",
      "position": [0, 20, 80],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "right_node",
      "component_id": "node_T_6x6",
      "position": [60, 20, 80],
      "rotation_deg": [0, 0, 0]
    }
  ],
  "rods": [
    {
      "id": "bridge_rod",
      "component_id": "rod_3mm",
      "from": {"node": "left_node", "port": "sub_x_neg", "side": "negative"},
      "to": {"node": "right_node", "port": "sub_x_neg", "side": "negative"}
    }
  ]
}
```

### 使用场景
- 连接左右两侧的竖直支撑
- 创建框架结构
- 增加结构稳定性

## 4. T型分支（T-Junction）

### 结构
使用 `node_T_6x6` 实现**两根光轴的连接**（一根穿过，一根插入）：

```
      |
    光轴（Y方向穿过）
      |
  [T_6x6] ←── 光轴（X负方向插入到孔心）
      |
      |
```

### 端口配置
- **主孔**：`main_y_pos` 和 `main_y_neg`（Y方向贯穿，through=true）
- **副孔**：`sub_x_neg`（X负方向，仅负向可插入，through=false，光轴插到孔心就停止）

### 关键理解
- **只能连接 2 根光轴**，不是三向！
- 主孔的光轴可以穿过节点
- 副孔的光轴只能插入到孔心位置（-10mm处）

### JSON 示例
```json
{
  "nodes": [
    {
      "id": "t_junction",
      "component_id": "node_T_6x6",
      "position": [30, 20, 80],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "node_below",
      "component_id": "node_SK8_support",
      "position": [30, 20, 0],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "node_above",
      "component_id": "node_T_6x6",
      "position": [30, 20, 140],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "node_left",
      "component_id": "node_T_6x6",
      "position": [20, 20, 80],
      "rotation_deg": [0, 0, 0]
    }
  ],
  "rods": [
    {
      "id": "rod_vertical",
      "component_id": "rod_3mm",
      "from": {"node": "node_below", "port": "rod_axis", "side": "positive"},
      "to": {"node": "node_above", "port": "main_y_neg", "side": "negative"}
    },
    {
      "id": "rod_branch",
      "component_id": "rod_3mm",
      "from": {"node": "node_left", "port": "main_y_pos", "side": "positive"},
      "to": {"node": "t_junction", "port": "sub_x_neg", "side": "negative"}
    }
  ]
}
```

**注意**：
- `rod_vertical` 穿过 `t_junction` 的主孔（Y方向）
- `rod_branch` 从左侧插入 `t_junction` 的副孔（X负方向），插到 X=-10mm 处停止

### 使用场景
- 从竖直链向侧面延伸
- 创建不对称结构
- 增加设计复杂度

## 5. 十字分支（Cross Junction）

### 结构
使用 `node_cross_6x6` 实现**两根光轴的垂直交叉**（都可以穿过）：

```
      |
    光轴（Z方向穿过）
      |
  [Cross] ←── 光轴（Y方向穿过）
      |
      |
```

### 端口配置
- **主孔**：`main_y_pos` 和 `main_y_neg`（Y方向贯穿，through=true）
- **副孔**：`sub_z_pos` 和 `sub_z_neg`（Z方向贯穿，through=true，位置在-10mm处）

### 关键理解
- **只能连接 2 根光轴**，不是四向！
- 两根光轴都可以穿过节点
- 两根光轴互相垂直（一根沿Y，一根沿Z）
- 副孔位置在 X=-10mm 处

### JSON 示例
```json
{
  "nodes": [
    {
      "id": "cross_center",
      "component_id": "node_cross_6x6",
      "position": [30, 20, 80],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "node_front",
      "component_id": "node_T_6x6",
      "position": [30, 60, 80],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "node_back",
      "component_id": "node_T_6x6",
      "position": [30, -20, 80],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "node_above",
      "component_id": "node_T_6x6",
      "position": [20, 20, 120],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "node_below",
      "component_id": "node_SK8_support",
      "position": [20, 20, 40],
      "rotation_deg": [0, 0, 0]
    }
  ],
  "rods": [
    {
      "id": "rod_y_axis",
      "component_id": "rod_3mm",
      "from": {"node": "node_back", "port": "main_y_pos", "side": "positive"},
      "to": {"node": "node_front", "port": "main_y_neg", "side": "negative"}
    },
    {
      "id": "rod_z_axis",
      "component_id": "rod_3mm",
      "from": {"node": "node_below", "port": "rod_axis", "side": "positive"},
      "to": {"node": "node_above", "port": "main_y_neg", "side": "negative"}
    }
  ]
}
```

**注意**：
- `rod_y_axis` 穿过 `cross_center` 的主孔（Y方向，位置在 X=30）
- `rod_z_axis` 穿过 `cross_center` 的副孔（Z方向，位置在 X=20，因为副孔在-10mm处）
- 两根光轴互相垂直交叉

### 使用场景
- 创建复杂的空间结构
- 多方向延伸
- 中心枢纽节点

## 6. 平行双轨（Parallel Rails）

### 结构
使用 `node_parallel_6x6_c10` 创建平行的双光轴：

```
  光轴1 ───→
  光轴2 ───→  (间距10mm)
```

### 端口配置
- **主孔**：`main_y_pos` 和 `main_y_neg`（原点，Y方向）
- **副孔**：`sub_y_pos` 和 `sub_y_neg`（-10mm处，Y方向）

### JSON 示例
```json
{
  "nodes": [
    {
      "id": "parallel_start",
      "component_id": "node_parallel_6x6_c10",
      "position": [0, 0, 80],
      "rotation_deg": [0, 0, 0]
    },
    {
      "id": "parallel_end",
      "component_id": "node_parallel_6x6_c10",
      "position": [0, 60, 80],
      "rotation_deg": [0, 0, 0]
    }
  ],
  "rods": [
    {
      "id": "rail_1",
      "component_id": "rod_3mm",
      "from": {"node": "parallel_start", "port": "main_y_pos", "side": "positive"},
      "to": {"node": "parallel_end", "port": "main_y_neg", "side": "negative"}
    },
    {
      "id": "rail_2",
      "component_id": "rod_3mm",
      "from": {"node": "parallel_start", "port": "sub_y_pos", "side": "positive"},
      "to": {"node": "parallel_end", "port": "sub_y_neg", "side": "negative"}
    }
  ]
}
```

### 使用场景
- 创建稳定的双轨结构
- 滑动机构的导轨
- 增强结构强度

## 💡 设计建议

### 1. 组合使用
这些模式可以自由组合：
- 竖直支撑链 + 横向桥接 = 框架结构
- T型分支 + 玻璃夹持 = 带玻璃的分支结构
- 十字分支 + 多个横向桥接 = 复杂空间结构

### 2. 灵活变化
- 不必严格遵循模式
- 根据设计需求调整
- 创造新的组合方式

### 3. 几何验证
- 确保端口对齐
- 检查光轴方向
- 验证坐标计算

### 4. 美学考虑
- 避免过于对称
- 适当错位布局
- 丰富视觉层次
