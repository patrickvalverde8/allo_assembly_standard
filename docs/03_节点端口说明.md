# 节点端口说明

## 节点结构

所有节点都有**主孔**和**副孔**（如果有）：
- **主孔**：原点位置的孔
- **副孔**：偏移位置的孔（通常在 -10mm）

## 节点详细说明

### 1. 十字连接件 (node_cross_6x6)

**结构**：
- 主孔：原点 [0, 0, 0]，Y 方向贯穿
- 副孔：[-10, 0, 0]，Z 方向贯穿

**端口**：
- `main_y_pos`: 主孔 Y 正向
- `main_y_neg`: 主孔 Y 负向
- `sub_z_pos`: 副孔 Z 正向
- `sub_z_neg`: 副孔 Z 负向

**使用示例**：
```json
{
  "from": {"node": "N1", "port": "main_y_pos", "side": "positive"},
  "to": {"node": "N2", "port": "main_y_neg", "side": "negative"}
}
```

### 2. T型连接件 (node_T_6x6)

**结构**：
- 主孔：原点 [0, 0, 0]，Y 方向贯穿
- 副孔：[-10, 0, 0]，X 负方向（仅负向）

**端口**：
- `main_y_pos`: 主孔 Y 正向
- `main_y_neg`: 主孔 Y 负向
- `sub_x_neg`: 副孔 X 负向（仅此方向）

**注意**：副孔只能从 X 负方向插入！

### 3. 平行连接件 (node_parallel_6x6_c10)

**结构**：
- 主孔：原点 [0, 0, 0]，Y 方向贯穿
- 副孔：[-10, 0, 0]，Y 方向贯穿

**端口**：
- `main_y_pos`: 主孔 Y 正向
- `main_y_neg`: 主孔 Y 负向
- `sub_y_pos`: 副孔 Y 正向
- `sub_y_neg`: 副孔 Y 负向

**使用示例**：两根平行光轴
```json
{
  "rods": [
    {
      "from": {"node": "N1", "port": "main_y_pos"},
      "to": {"node": "N2", "port": "main_y_neg"}
    },
    {
      "from": {"node": "N1", "port": "sub_y_pos"},
      "to": {"node": "N2", "port": "sub_y_neg"}
    }
  ]
}
```

### 4. 固定环 SC6 (node_SC6_ring)

**用途**：夹持玻璃面板

**结构**：
- 环厚度：8mm
- 原点：环中心
- 光轴方向：Z 轴（正负均可）

**端口**：
- `rod_axis`: 光轴孔（Z 方向，正负均可）

**面板位置**：
- 面板应放在环的 **±4mm** 位置
- 面板厚度：3mm
- 两个环间距：11mm（8mm + 3mm）

**使用示例**：
```json
{
  "nodes": [
    {"id": "ring_top", "position": [0, 0, 100]},
    {"id": "ring_bot", "position": [0, 0, 89]}
  ],
  "panels": [
    {
      "id": "glass",
      "position": [0, 0, 94.5],
      "thickness_mm": 3
    }
  ],
  "rod_attachments": [
    {"node": "ring_top", "rod": "rod1", "offset_mm": 100},
    {"node": "ring_bot", "rod": "rod1", "offset_mm": 111}
  ]
}
```

**计算**：
- 环1 在 Z=100（环中心）
- 环2 在 Z=89（环中心）
- 间距 = 100 - 89 = 11mm
- 面板在 Z=94.5（环1 的 -4mm 或环2 的 +4mm）

### 5. 支撑座 (node_SK6_support, node_SK8_support)

**结构**：
- 原点：光轴与底座上表面交点
- 光轴方向：Z 正向

**端口**：
- `rod_axis`: 光轴孔（Z 正向）

## 校验规则

系统会自动检查：

1. **光轴对齐**：光轴必须沿端口轴向
2. **插入方向**：必须符合 `insert_from` 规则
3. **端口占用**：每个端口最多 1 根光轴
4. **孔心对齐**：光轴必须穿过孔心

## 常见错误

### ❌ 错误：使用不存在的端口
```json
{"node": "N1", "port": "x_pos"}  // 十字连接件没有 x_pos
```

### ✅ 正确：使用正确的端口名
```json
{"node": "N1", "port": "main_y_pos"}  // 主孔 Y 正向
{"node": "N1", "port": "sub_z_pos"}   // 副孔 Z 正向
```

### ❌ 错误：副孔方向错误
```json
// T型连接件的副孔只能 X 负向
{"node": "T1", "port": "sub_x_neg", "side": "positive"}  // 错误！
```

### ✅ 正确：
```json
{"node": "T1", "port": "sub_x_neg", "side": "negative"}  // 正确
```

## 端口命名规则

- `main_*`: 主孔（原点位置）
- `sub_*`: 副孔（偏移位置）
- `*_pos`: 正向
- `*_neg`: 负向
- `*_y_*`: Y 方向
- `*_z_*`: Z 方向
- `*_x_*`: X 方向
